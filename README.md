# my-first-pr

A practice repository for learning the GitHub pull request workflow.

## What this is

A safe sandbox for experimenting with branches, commits, and pull requests —
created while opening my first PR with Claude Code.

## Getting started

```bash
# Clone the repository
git clone https://github.com/farboddanesh-eng/my-first-pr.git
cd my-first-pr

# Create a branch, make a change, then open a pull request
git checkout -b my-change
```
